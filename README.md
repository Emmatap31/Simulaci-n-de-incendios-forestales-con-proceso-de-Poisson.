# Simulación-de-incendios-forestales-con-proceso-de-Poisson.
Simulación en Python de incendios forestales en una zona a lo largo del tiempo utilizando un Proceso de Poisson en la simulación de los inicios de los incendios y el modelo de propagación propuesto por Carlos Díaz-Ávalos y Pablo Juan en "Modelling the spatial evolution wildfires using random spread process"
